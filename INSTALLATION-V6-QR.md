# Installation V6 — QR parent

## 1. GitHub Pages
Téléverse tous les fichiers de ce dossier dans le dépôt `okajb/rcsq-m10` en remplaçant les anciens fichiers de même nom.

## 2. Firebase — une seule fois
Dans le projet Firebase **rcsq-m10-direct** :

1. **Firestore Database > Rules**
2. Remplace tout par le contenu de `firestore.rules`
3. Clique **Publish / Publier**
4. Va dans **Authentication > Sign-in method**
5. Active **Anonymous / Anonyme** si ce n'est pas déjà fait

## 3. Sur ton iPhone
Ouvre `https://okajb.github.io/rcsq-m10/` dans Safari puis relance l'application.

Pendant un match :
- touche **📲 Partager stats avec un parent**
- connecte-toi au compte coach si l'app le demande
- le QR s'affiche
- le parent le scanne avec son téléphone

Le parent ne voit que les prénoms du match, les joueurs actuellement sur le terrain et les compteurs.
